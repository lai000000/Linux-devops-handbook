

> 思路：先部署 1 台基础模板虚拟机，完成操作系统安装、基础软件、系统参数全部初始化，**再通过完整克隆批量生成所有集群节点**，大幅减少重复部署工作量。

## 操作步骤

### 1. 部署基础模板虚拟机

1. 在 VMware 中新建虚拟机，安装 CentOS 操作系统。
2. 完成系统基础初始化：安装基础工具包、关闭防火墙、关闭 SELinux、配置 yum 源等前置操作。
3. **模板机不要设置静态 IP，主机名保持默认**，克隆出来之后再单独修改每一台节点的 IP 与主机名，避免 IP 冲突。

### 2. 通过克隆生成全部集群节点

模板虚拟机全部配置验证完毕，使用 VMware 克隆功能，**选择【创建完整克隆】**，分别生成 4 台虚拟机：

- k8s‑master01
- k8s‑node01
- k8s‑node02
- jenkins‑harbor

> ⚠️重要：禁止使用链接克隆，链接克隆依赖原始模板机，模板机异常会导致全部节点故障。

### 3. 逐个配置静态 IP 地址

每一台克隆出来的虚拟机，修改网卡配置文件，设置对应规划表内的**静态 IP、网关、DNS 服务器**


修改完成重启网卡服务，同时修改本机主机名，与规划表保持一致。

### 4. 网络连通性校验

每台虚拟机配置完 IP 之后，必须验证外网连通性：

bash

```
ping baidu.com
```

![](docs/VMware/assets/Pasted%20image%2020260820101400.png)

#### 故障排查

- ping 不通外网，优先排查：虚拟机网卡模式、静态网关、DNS 配置；
- 打开 VMware 虚拟网络编辑器，确认 NAT 模式的子网、网关地址，和虚拟机内部配置保持一致；
- 检查虚拟机网卡是否正常启用。

## 重要注意事项

1. harbor 节点磁盘 80G，镜像仓库会持续占用存储空间，不建议缩小磁盘容量。
2. 所有节点后续部署 K8s，需要关闭防火墙、SELinux，**模板机阶段就可以提前关闭**。
3. 克隆之后每台机器必须修改：主机名、静态 IP，否则集群会出现 IP / 主机名冲突。
4. 全部节点网络 ping 通外网，才可以进行后续 K8s 组件安装。
